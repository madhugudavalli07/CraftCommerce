# CraftCommerce.Auth

Auth microservice for CraftCommerce. This is a minimal ASP.NET Core Web API scaffold.

Run locally:

```bash
cd CraftCommerce
dotnet build
dotnet run --project src/AuthService/CraftCommerce.Auth.csproj
```

Endpoints:

- GET /weatherforecast (template example)
