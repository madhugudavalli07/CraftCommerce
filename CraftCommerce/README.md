# CraftCommerce

This folder contains the solution for CraftCommerce. Add microservice projects under `src/` and add them to the solution.

Quick start (example):

```bash
cd CraftCommerce
dotnet build
# Example: dotnet run --project src/AuthService/CraftCommerce.Auth.csproj
```

The solution file is `CraftCommerce.sln` and projects should target .NET 8.
