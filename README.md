# CraftCommerce
Microservices E-Commerce Application using ASP.NET Core, Angular and Azure

## Local backend solution

The `CraftCommerce` solution lives under the `CraftCommerce` folder and will contain multiple microservice projects.

Quick run (example when a project exists):

```bash
cd CraftCommerce
dotnet build
# Example: dotnet run --project src/AuthService/CraftCommerce.Auth.csproj
```

Add microservice projects under the `CraftCommerce` folder and add them to the `CraftCommerce.sln` solution with `dotnet sln add`.
