# CraftCommerce Requirements

## Project Goal

Build a Microservices-based E-Commerce Application using:
- ASP.NET Core Web API
- Angular
- SQL Server
- Azure

## Customer Features

- Register
- Login
- Browse Products
- Search Products
- Add To Cart
- Place Order
- View Orders

## Admin Features

- Add Product
- Update Product
- Delete Product
- Manage Orders

## Microservices

1. User Service
2. Product Service
3. Cart Service
4. Order Service
